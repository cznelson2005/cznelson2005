## Featured Project

### Agentic AI Workflow for Customer Support Intelligence

This project explores how agentic AI workflows can convert unstructured customer support conversations into structured business insights.

```text
Raw support tickets
→ Preprocessing
→ Issue classification
→ Root cause summarization
→ Pattern detection
→ Recommended actions
→ Executive summary
```

The workflow is designed to help teams:

* Classify customer issue types
* Summarize root causes
* Detect recurring complaint patterns
* Generate recommended actions
* Produce executive-level summaries for product, CX, and operations teams

The goal is not only to summarize tickets, but to help teams identify recurring customer pain points, prioritize root causes, and reduce manual analysis effort.

**Skills demonstrated:**
LLM workflow design, Python, Gemini API, async processing, text classification, summarization, clustering, root cause analysis, CX analytics, and product/operations insight generation.
